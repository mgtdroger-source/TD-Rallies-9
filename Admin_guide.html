Admin — Entries & Rally Setup

Overview

The Admin page is the starting point for every rally. It is used to create the rally record, define rally days, speed groups, and enter competitor details. Admin is the single source of truth for rally structure and entrant data. All other pages (Schedule and Controls) read from the data created here.

Admin is also the gateway to the app’s Google-based entry and timing system. Google Forms are used to collect entries, STC times and Marshal times, while Google Sheets stores and organises the returned data ready for download into the rally project. The initial Google connection is a major one-time setup. Complete it carefully using the Setting up guide provided in the Entries card.

The page has a Normal/Compact button. Toggling this changes the page size.

Typical Workflow

  1. Enter the rally title and set the Rally Workspace for project saves.
  2. Set the rally days, dates, start times, intervals, speed groups and routes.
  3. Enter or download entrants, assign speed groups and routes, then sort when entries are complete.
  4. Use Schedule and Timeline to prepare timing and any day-specific start delays.
  5. Prepare Google Entries if using online entry forms, share the link and download the entries.
  6. Save the project; use Print or Export Admin when a starting list is needed.

Understanding the Admin Page

The Admin page has three main working areas:

  • Rally setup: Set the rally days, dates, start times, speed groups and number of routes for each day.
  • Control panel: Name and manage the rally project, save or load work, print entrant information and open the Entries card.
  • Entrant table: Enter competitors, assign speed groups and routes, and arrange the starting order once entries are complete.

How Admin connects to the other pages: Schedule uses the rally days, routes and speed groups established here. Controls uses the entrant details, route allocations and start times to calculate expected control times and results.

Rally Setup — Days, Speed Groups and Routes

  • Select the number of Rally days using the day selector, up to 7 days.
  • Dates, click the calendar icon, select the starting date, following day dates cascade, for a rest day increment the date after the rest day, further days will cascade again.
  • Starting times, click the clock icon, select the start time for each day.
  • Increment, the start time interval which can be incremented in 30 sec steps, the default is 1 minute.
  • Select the number of Speed Groups using the selector, up to 4 speed groups.
  • Adjust the speed for each Speed Group as required, the speed of a slower group cannot exceed that of a faster group, as the speed of a faster group is decremented it will decrement the speed of the slower group below.
  • The speed selected is the maximum speed that will be available when setting speeds in the route schedule, the speed allocated to an entrant and for result calculations. If a selected speed is changed allocations update accordingly.

    • Note: if a speed is increased then a review of the schedule speeds will be required, these do not automatically increment, they only decrement automatically.

  • Routes, when 2 is selected, each rally day requires two schedules. Each route must have the same number of controls such as STCs and Marshals.

With 2 routes selected the table of the Admin page gains an additional column to assign entrants to a route.

Route allocations are not subject to sort, so they must be reviewed once an entry table has been sorted by speed group. The first car away should be assigned to route 1.

Admin Control Panel

  • Enter Rally Title, your Rally Name, which is the first detail to be entered when commencing a new rally, next to the title is the rXXX number, it increments each time you save the project.
  • ADD ROW adds an additional entrant row to the bottom of the table. Downloaded entries automatically add rows.
  • Sort used to arrange the table of entrants into speed group order. Sort the entrant table is sorted.
  • Save save your work to a selected workspace folder.
  • Load select a Rally file from your workspace folder, note: loading will overwrite your current work, so consider saving prior to loading.
  • Print print entrant details and their day starting times.
  • Entries when selected it presents a card which is the gateway to automation, refer to Google integration below.

Entrant Management

Entry and management of competitor details, either manually or fully automated. Entrants can be sorted by speed group, including start delays between groups. Add row button: Adds a new entrant row to the bottom of the table.

Note: Rally numbers and start times cannot be edited in the table. Rally number sequence is fixed.

Entry column and gear icon.

As each entry is added to the table an index (row number) is assigned to that entrant, later when the table is sorted the index will remain with that entrant.

Entry row gear menu

  • Insert a new row above or below, index numbers update maintaining sequence.
  • Copy row, entrant details excluding Rally number and times which are fixed.
  • Paste, Pasting is only allowed into an empty row.
  • Delete, when selected a confirmation is presented before the row is removed.

Note: when rows are inserted or deleted sequence numbers are updated.

Speed Group column

Clicking a Speed group cell in the table will open a selector menu from which to pick a speed group, once selected the cell will be colour coded for ease of reference. If the group speed is amended table cells will update automatically. If an entrant allocated in a slower group and that group option is removed, then that entrant will be promoted to the next higher speed group.

Note: If the omitted speed group is reinstated during the same work session, then entrants will be returned to that group.

Sorting entrants

The sort function is used to arrange the table of entries into speed groups, typically slowest to fastest. Sort should only be used when all entries have been received. Once a table is sorted, options such as Add Row, the gear icon options and download of data are no longer available. If late entries are to be accommodated, then select sort and restore the tables original order. When a table is sorted the original entry index number will remain with the entrant.

Notes

  • When sorting Rally numbers and start times remain fixed.
  • Route allocation remains with the entrant and can be updated as required.
  • Special case, when a table is sorted, an entrant's SG can be changed, but his rally number and start time will remain the same.

Start Delays (per rally day)

After sorting entrants slowest to fastest, the Include Start Delays option can be used to apply the day’s start delays as set in Timeline. The choice is remembered separately for each rally day.

Timeline is where start delays are adjusted; Admin uses those day-specific delays when displaying and printing entrant start times. If no start delays are required for a day, leave the delays at zero or do not select the option.

Save, Load and Rally Workspace

Each page has a Save and Load button, they all function in the same way.

Admin includes additional options for managing file saving. Select Tools to view these options.

First a file Workspace must be selected.

  • Setting up your workspace, for example a folder in My documents.

    • In order to save your projects on your computer, a workspace folder is required. Selecting Set Rally Workspace opens a Windows picker, enabling you to navigate to where you want to save projects, for example a new folder in My Documents named "Rallies".

    Based on your chosen Rally title, a new sub folder is created within the Rallies folder when you save. Inside that folder will be your project file with its rXXX reference. Each time you save the same project, rXXX is incremented by 1 and shown on each of the program pages.

  • Save As, enables you to save all current project data giving it a new Rally Title.
  • Save As Template, only saves the data related to the Schedule page, Admin entries are reset as well as prior control card ATA records and scores, Google upload history is reset. Save giving the project a new Rally Title. The template providing schedules which you can then edit to create a new Rally
  • Load, select a previously saved project.
  • New Rally, resets all the pages clearing any prior work, a new Title is required.

File Save and Loading protocol, each time you save a project its rXXX increments, should you load a prior version you are prevented from saving it so you do not overwrite the last saved version, the alternative after loading a previous version is to use Save As..

Each project saved has its own unique identity and rXXX series. You can shuffle back and forth between projects.

Google Integration

When Entries is selected, the Entries card opens. This is the gateway to the app’s Google-based entry and control-data system.

The app uses Google Forms to collect rally entries, STC times and Marshal times. Google Sheets stores and organises the submitted information so it can be reviewed and downloaded into the Admin and Controls pages.

The initial Google connection is a major one-time setup. Select Setting up guide in the Entries card and follow the instructions carefully. Once completed, the same connection can be used for future rallies.

For each rally, the app then creates and manages the required Google folders, forms and data sheets automatically. Normal rally use requires little direct interaction with Google.

One-time setup

  • Open the Entries card and select Setting up guide. Complete the full Google setup before entering the mobile number and connection URL.
  • In the setup section of the card enter your mobile number, including the international prefix. For example, use +27 followed by the number without the leading 0.
  • Copy the Google connection URL produced during the setup process into the URL field.
  • Once both the mobile number and URL have been entered, select Save & test.
  • The status at the top of the card should change to Connected, confirming that the setup is complete.

Uploading and Downloading Entries

Entries card

When the Entries card is open there are rows of buttons, first in the lower section of the card is Setup, if not already set up click the Setting up guide button and follow the instructions.

Sharing the entry link

Until entry data has been uploaded these buttons will be greyed, but after upload they will be lit. The buttons are used to select the method of sending a link to the Rally entry form, if WhatsApp (WA) is selected you will need to have the WA app installed on your machine. When WA is selected a message and link will be sent to yourself which you can then distribute further.

WA is by far the most convenient method of sharing form links, and most people today are comfortable using WA, once all the entrant details have been gathered consider setting up a WA group which will make the distribution of the result (STC) form so much simpler.

Uploading entry data

Before uploading entry data ensure you have set up the rally Speed Groups options and speeds, to the left of upload is displayed the Rally Title, this is the text that will appear at the top of the Google entry form, the text can be edited as required.

Note: uploading of data takes a little while, so be patient a lot is being created.

Reviewing and downloading entries

View response forms button, opens a new tab presenting the Google form responses.

Open entry data button, opens a new tab presenting the worksheet of processed Google data that is ready for download.

Note: An entrant can submit more than one response, but only their last will appear in the worksheet ready for download.

Download entry data is enabled when entry data is available. When Google has received new or changed entry data since the last successful download, the button alternates with New entries waiting in a lighter blue to draw attention to the update.

After a successful download the new-data indication stops and the button returns to its normal state. A fresh entry-data upload also resets the new-data marker, so the rebuilt Google sheet does not create a false new-entry warning.

Note: The new-entry check is lightweight and is made when the Entries card is opened. It does not continuously poll Google while the card remains open.

When entry data is downloaded it overwrites any prior data in the entries table.

Tip: review entry data worksheet before downloading to gain an appreciation of the entries received.

Printing and Exporting

Print produces entrant details and the starting times for the selected rally days. When day-specific start delays are enabled, the printed start times include them.

Export Admin XLSX creates one consolidated spreadsheet of the entrant information, including the rally-day starting times, for review or further use.

Advanced Recovery

Last resort only. Clearing browser storage and deleting Google Drive folders can permanently remove locally held settings or cloud results. Before attempting recovery, save a copy of the rally project, export any required entries and Controls results, and preserve the Google data.

Use this procedure only when ordinary reconnecting, reloading or restoring a saved project has failed, and after confirming which data and folders are safe to remove.

Existing procedure (destructive): This procedure is rarely needed and should only be used if normal recovery options have failed. If things go wrong for any reason, follow these steps. Select F12 on your keyboard, select "Applications", in the left panel select "file://" from below "Local storage", right click file then select "clear".

The local memory is now cleared. Go to your Google Drive, and delete the folder "Time & Distance Rallies", also delete the folder from the trash bin. Now repeat the Google setting up process. Potentially you may have a corrupted saved rally file, so consider deleting that folder so you will be starting over from a totally clean base.
